# PD-Proxy — Интеграционные тесты

## Обзор

Набор из **685+ тестов**, проверяющих работу PD-Proxy API по HTTP.
Тесты работают как автономный Python-скрипт — SSH-доступ к серверу не нужен, достаточно HTTP.

### Группы тестов

| Группа | Описание | Кол-во | Метод запуска |
|--------|----------|--------|---------------|
| **A** | Прямое обнаружение ПДн (21 категория × ~15 сэмплов) | ~315 | параллельно |
| **B** | Граничные / edge-case сценарии | ~100 | параллельно |
| **C** | Анти-FP (негативные: не должны давать ложных срабатываний) | ~100 | параллельно |
| **D** | Комбинации нескольких категорий ПДн в одном тексте | ~120 | параллельно |
| **E** | Идемпотентность (повторный `payload_id` → результат идентичен) | ~50 | последовательно |
| **F** | Нагрузочный тест (100 соединений × 10 сек) | 100 пейлоадов | цикл |

## Быстрый старт

### Способ 1: Скрипт `run_tests.sh` (рекомендуется)

```bash
# Тесты на локальный сервер (localhost:8080)
./run_tests.sh

# Тесты на удалённый сервер
./run_tests.sh http://168.100.11.100:8080
```

Скрипт автоматически:
1. Проверяет доступность сервера (`GET /health`)
2. Создаёт виртуальное окружение `.venv-test/`
3. Устанавливает зависимости из `requirements-test.txt`
4. Запускает тесты и выводит результаты
5. Сохраняет отчёты в `tests/test-report.txt` и `tests/test-report.json`

### Способ 2: Ручной запуск

```bash
# 1. Установить зависимости
pip install aiohttp

# 2. Запустить (по умолчанию — http://168.100.11.100:8080)
python3 tests/test_server_live.py

# Или указать другой адрес:
PD_PROXY_URL=http://localhost:8080 python3 tests/test_server_live.py
```

## Предварительные требования

1. **Python 3.10+** установлен
2. **PD-Proxy запущен** и доступен по HTTP:
   ```bash
   # Docker:
   docker compose up -d

   # Или нативно:
   cd /path/to/pd-proxy
   source .venv/bin/activate
   gunicorn app.main:app -b 0.0.0.0:8080 -w 4 -k uvicorn.workers.UvicornWorker
   ```
3. **Зависимость**: `aiohttp>=3.9.0` (устанавливается автоматически через `run_tests.sh`)

## Известные ограничения (Known Limitations)

Regex-режим (`mode=fast`) имеет ограничения, которые не считаются ошибками:

| Категория | Ограничение | Пример |
|-----------|-------------|--------|
| Знаменитые люди | ФИО совпадает с regex-паттерном | «Александр Сергеевич Пушкин» |
| Вымышленные персонажи | Аналогично | «Анна Каренина», «Родион Раскольников» |
| Топонимы | Паттерн адреса ловит улицу | «улица Пушкина» |
| Голые числа без контекста | 10 цифр без слова «паспорт» | `4510123456` |
| Голые даты без контекста | Дата без слова «дата рождения» | `01.01.1990` |

Эти тесты помечены `known_limitation=True` и **не влияют на pass rate**.
Для снижения FP рекомендуется использовать `mode=full` (regex + FastJev-классификатор).

## Добавление тестов

Каждая группа построена как функция `build_group_X()`, возвращающая список `TC`:

```python
from test_server_live import TC

# Позитивный тест (ожидаем обнаружение ПДн)
TC(group="A", tag="passport-16", payload="паспорт 4580 567890",
   exp_cats=["passport"], exp_pd=1)

# Негативный тест (ожидаем отсутствие ПДн)
TC(group="C", tag="c-new-01", payload="обычный текст",
   neg=True, exp_pd=0)

# Known limitation (известное ограничение)
TC(group="C", tag="c-famous-16", payload="Марина Цветаева",
   neg=True, exp_pd=0, known_limitation=True)
```

### Поля `TC`:

| Поле | Тип | По умолчанию | Описание |
|------|-----|-------------|----------|
| `group` | str | — | Группа: A/B/C/D/E/F |
| `tag` | str | — | Уникальное имя теста |
| `payload` | str | — | Текст для отправки |
| `exp_action` | str | `"masked"` | Ожидаемое `action` в ответе |
| `exp_cats` | list | `[]` | Ожидаемые категории ПДн |
| `exp_pd` | int | `1` | Минимальное `pd_found` |
| `neg` | bool | `False` | Негативный тест (ожидаем `pd_found=0`) |
| `mode` | str | `"fast"` | Режим: `fast` / `full` |
| `sid` | str | `"default"` | `system_id` |
| `pid` | str? | `None` | `payload_id` (None → авто UUID) |
| `known_limitation` | bool | `False` | Известное ограничение (не считается ошибкой) |

## Код возврата

| Код | Значение |
|-----|----------|
| `0` | Все тесты пройдены (known limitations не считаются) |
| `1` | Есть реальные провалы |
