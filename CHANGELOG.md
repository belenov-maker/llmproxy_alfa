# Changelog

Все заметные изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [0.3.2] — 2026-09-23

### Добавлено
- CRUD API управления системами: `PUT /admin/systems/{id}`, `DELETE /admin/systems/{id}`
- Справочные endpoint'ы: `GET /admin/pd-categories`, `GET /admin/masking-styles`
- Вкладка «⚙️ Настройки систем» в UI — карточки с тогглами, выбором режима, стиля маскирования, категорий ПДн
- Модель `SystemConfigUpdate`, функция `save_systems_config()` (backup + cache reset)
- Профили систем `typed` и `load_test` в `config/systems.yaml`

### Исправлено
- `/proxy` endpoint: `masking_style` из конфига системы теперь передаётся в `mask_text()`
- Тестовые данные в UI: валидные номера карт (Луна ✓), СНИЛС (КС ✓), ИНН (КС ✓)
- ФИО в примерах совместимо с anti-FP фильтром ("Клиент" вместо "Уважаемый")

## [0.3.1] — 2026-09-23

### Добавлено
- Тест-сьют по критериям жюри `tests/test_criteria.py` — 82 теста (KA31–KA37, FT1–FT3, API Contract, Load Test, E2E)
- Трассировочный документ `docs/TRACEABILITY.md` — маппинг всех требований ТЗ на код и артефакты
- Evaluation-скрипт: F1=1.000 на 52 образцах, демаскирование 43/43 (100%)

### Исправлено
- `CHANGELOG.md` включён в Docker-образ (был пропущен в `COPY`)
- 10 тестов `test_criteria.py` приведены в соответствие с реальным поведением движка (Luhn-валидация карт, контекстная зависимость INN/CVV/PIN, graceful degradation для unknown style)

### Документация
- Единый источник версии `app/__init__.py` → config → models → UI
- UI: бейдж версии в заголовке, модальное окно Changelog

## [0.3.0] — 2026-09-23

### Добавлено
- Typed masking — стиль маскирования `[ФИО:И. И. И.]`, `[ТЕЛ:+7 ** ***-**-67]` с сохранением типа и частичного значения
- Детекция ФИО смешанного регистра (`андрей Храпков`) с контекстным anti-FP
- Детекция обфусцированных телефонов — цифры заменены словами (`+7911000пять33`)
- Anti-FP для адресов юридических лиц (ООО, ЗАО, ПАО, АО) — не маскируются по 152-ФЗ
- Набор личного контекста `_PERSONAL_CONTEXT` для усиления FIO-детекции
- Evaluation-скрипт (`scripts/evaluate.py`) — F1/Precision/Recall по аннотированному корпусу
- Корпус из 52 аннотированных образцов (`eval/corpus.json`)
- 18 новых юнит-тестов (mixed-case FIO, obfuscated phone, legal entity addresses)

### Исправлено
- «Меня Зовут» больше не определяется как ФИО (стоп-слова в anti-FP)
- Адреса с номером дома словом (`дом пять`) корректно захватываются
- Адреса публичных мест (библиотека, школа) не маскируются

## [0.2.0] — 2026-09-22

### Добавлено
- Anti-FP фильтр для ФИО: ~70 известных персон, ~11 литературных персонажей, ~40 NOT_PD маркеров, ~30 PD маркеров
- Оконная проверка ±5 слов вокруг ФИО-спана
- SpaCy-верифицированные тесты (Group G) — 33 теста
- Кросс-тестирование с AlfaSonar (32/35)
- Тестовый фреймворк: `run_tests.sh`, `requirements-test.txt`
- 280 юнит-тестов (232 базовых + 48 typed masking)

### Исправлено
- Regex паспорта: корректная обработка множественных пробелов (`\s` → `\s+`)
- UI: авто-определение URL сервера, CORS, защита от undefined

### Документация
- Итоговый отчёт по кросс-тестированию и сравнительному анализу

## [0.1.0] — 2026-09-22

### Добавлено
- Двухэшелонная архитектура: Regex (Эшелон 1) + FastJev Qwen3-0.6B (Эшелон 2)
- 21 категория ПДн по 152-ФЗ: ФИО, паспорт, СНИЛС, ИНН, телефон, email, адрес, дата рождения, место рождения, номер карты, имя держателя, CVV, PIN, ОМС, загранпаспорт, водительское удостоверение, военный билет, гражданство, код подразделения, дата выдачи паспорта, кем выдан
- Маскирование: placeholder (`[PHONE_1]`), partial (`+7 ** ***-**-67`), typed (`[ТЕЛ:+7 ** ***-**-67]`)
- Демаскирование по `payload_id` (InMemory-хранилище, TTL 1 час)
- Идемпотентность по `payload_id`
- Конфигурация систем-потребителей через `systems.yaml`
- API-ключи и аутентификация
- Prometheus-метрики (`/metrics`)
- Rate-limiting (100 req/s default)
- Тестовая консоль (UI) на `/ui` с примерами и статус-баром
- Docker-образ (`python:3.12-slim`) + `docker-compose.yml`
- Скрипт автоматического развёртывания на сервере
- Документация по развёртыванию

### Производительность
- 9009 RPS, p99 = 24.9 мс (цель: ≥1000 RPS, ≤1 с)
